# Social-Aware Task Offloading in Vehicular Social Networks using Deep Reinforcement Learning

This repository provides the official implementation for the paper:
*"Deep Reinforcement Learning for Intelligent Task Offloading in Vehicular Social Networks"*

## Repository Structure
- `vsn_env.py`: Multi-step Markov Decision Process (MDP) simulation environment with dynamic vehicle mobility, local CPU queueing delays, and V2V link failure probability based on Social Trust.
- `train_dqn.py`: Training script for the proposed Deep Q-Network (DQN) agent utilizing PyTorch.
- `evaluate_baselines.py`: Benchmark evaluation comparing Proposed DRL-Social against Local Only, Greedy, GA, and Double-DQN schemes, generating reproducible figures.

## Requirements
- Python 3.8+
- PyTorch 1.12+
- NumPy
- Matplotlib
